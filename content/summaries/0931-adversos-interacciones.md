## Efectos adversos característicos
| Fármaco | Efecto que se pregunta |
|---|---|
| Nitratos, dipiridamol | **Cefalea** |
| Betabloqueador no selectivo | **Broncoespasmo**; lipofílicos: **pesadillas e insomnio** |
| Verapamilo | **Estreñimiento** |
| Amlodipino | Edema maleolar |
| iSGLT2 | **Infecciones genitales por hongos**, cetoacidosis euglucémica |
| Ivabradina | **Fosfenos** (bloqueo de If en retina) |
| Amiodarona | **Fotosensibilidad** y piel azul-grisácea, tiroides, fibrosis pulmonar, hepatitis, **neuropatía óptica**, **epididimitis**, depósitos corneales |
| Procainamida | **Agranulocitosis**, lupus inducido |
| Tiazidas | **Hiperuricemia**, hiponatremia, hiperglucemia |
| Quinidina | **Cinconismo** (tinnitus, cefalea, visión borrosa) |
| Heparina a largo plazo | **Osteoporosis**, TIH |
| Warfarina | Necrosis cutánea (déficit de proteína C), **síndrome de los dedos morados** (ateroembolia), calcifilaxis |
| Ticagrelor | Disnea, pausas ventriculares |
| Adenosina | **Sensación de muerte inminente**, rubor, broncoespasmo |
| Dipiridamol / regadenosón | **Dolor mandibular** |
| Aspirina | **Enfermedad respiratoria exacerbada por AAS** (asma + pólipos nasales) |
| Estatinas | Mialgias, rabdomiólisis, **miopatía necrotizante autoinmune anti-HMGCR** (persiste al suspender) |
| IECA / ARA II en el embarazo | **Fetopatía** (oligohidramnios, insuficiencia renal fetal) |
| Captopril | **Sabor metálico** (disgeusia) |
| Dobutamina | **Miocarditis por hipersensibilidad (eosinofílica)** |
| Infiltración de noradrenalina | Antídoto local: **fentolamina** |
| Trimetoprim, cimetidina, dolutegravir, iSGLT2 | **Bloquean la secreción tubular de creatinina** (la elevan sin daño renal) |
| Sacubitrilo | Teórico: menor degradación de **β-amiloide** (sin señal clínica) |
| Clonidina | Rebote hipertensivo al suspender |

## Interacciones
- **CYP3A4**: inhibidores (**claritromicina**, **eritromicina**, azoles, **ritonavir/cobicistat**, diltiazem, verapamilo, **zumo de pomelo**) suben simvastatina, atorvastatina, ticagrelor, rivaroxabán y apixabán; inductores (**hierba de San Juan**, rifampicina, carbamazepina) los bajan. **Simvastatina ≤20 mg** con amlodipino o amiodarona.
- **CYP2C9** (warfarina, **cotrimoxazol**, amiodarona, fluconazol): con amiodarona **bajar la warfarina un 30–50 %**. Farmacogenética: **VKORC1** y CYP2C9.
- **CYP2C19**: activa el clopidogrel (portadores de alelos de pérdida de función responden menos).
- **CYP2D6**: la **paroxetina** sube metoprolol y propafenona.
- **Glicoproteína P**: amiodarona, verapamilo, dronedarona, quinidina y ciclosporina suben **digoxina** (**reducirla a la mitad** con amiodarona) y dabigatrán (110 mg/12 h con verapamilo). **Edoxabán 30 mg** con inhibidores potentes de gp-P.
- **SLCO1B1**: variante asociada a miopatía por simvastatina. **Pravastatina** y rosuvastatina tienen menos interacciones por CYP.
- Hiperpotasemia: **AINE**, trimetoprim, **sustitutos de la sal con potasio**, aliskireno con IECA/ARA II (doble bloqueo contraindicado en diabéticos). Los AINE además retienen sodio y descompensan la IC.
- **Colestiramina** reduce la absorción de otros fármacos (separar tomas).
- **IMAO + tiramina** (quesos curados): crisis hipertensiva. **Aspirina >100 mg** reduce la eficacia del ticagrelor.
- Contraste yodado: **suspender la metformina** si el FG es bajo.
- Fármacos que alargan el QT: consultar **CredibleMeds**.
